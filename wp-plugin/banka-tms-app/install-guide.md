# Banka TMS App Plugin

## Install in WordPress

1. Copy the folder `banka-tms-app` into `wp-content/plugins/`.
2. Activate it from the WordPress Plugins screen.
3. The plugin will create the following pages automatically:
   - Dashboard
   - Tasks
   - Users
   - Vendors
   - Settings
4. Open the pages to test the UI.

## Notes

- The plugin uses a custom blank-page template so it is less affected by the active theme.
- The current version includes a dashboard shell, task management UI, and user creation UI.
